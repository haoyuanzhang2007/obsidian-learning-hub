# Learning Hub

**简体中文** · [English](README.en.md)

**Learning Hub v1.1.0** 是 Obsidian 桌面版的学习工作空间。课程、预习、主笔记、回忆、复习、作业、Tutorial、Lab、待办和日程在同一个插件中管理，原始 Markdown、PDF 与 Notebook 保留在自己的 vault 中。

[下载 v1.1.0](https://github.com/haoyuanzhang2007/obsidian-learning-hub/releases/tag/1.1.0) · [版本变更](CHANGELOG.md) · [提交问题](https://github.com/haoyuanzhang2007/obsidian-learning-hub/issues)

首次启用只建立必要目录与入口，默认课程与待办为空。发布包不附带个人课程、作息规划、资料、聊天记录、账号或密钥。已有同名入口笔记会被保留。

## v1.1.0 更新

- **两种日程视图**：任务总览一次查看七天的学习任务；三日日历展示课程、任务、起床、睡眠、用餐、运动与休息，选中的日期更宽。
- **排程与调整分开**：Codex 生成七天草案，已确认日期不会重复生成；DeepSeek 支持连续对话调整现有日程。时间规则独立管理，预览后确认应用。
- **待办更完整**：紧急任务优先排，置顶仅用于展示；可填预计用时，也可设置没有预计结束日期的长期项目。
- **学习任务自动关联**：已上传且纳入学习范围的讲次生成预习待办；回忆与复习按学习状态、解锁日期同步，未解锁事项不在待办列表铺开。日历课程仍用于排程上下文，不会凭空创建讲次。
- **作业详情与小问错题**：上传后自动整理题目、估算用时并关联待办；从卡片进入详情，支持将大题中的具体小问加入错题。
- **Tutorial 与 Lab 资料库**：三类资料共用一致的卡片、详情、上传入口和空状态；可组合 PDF、Markdown、TXT 与 `.ipynb`，标记题目、答案、说明或混合资料。
- **复习参考练习资料**：按关联讲次提供 Tutorial / Lab 题目、参考答案、代码模板与来源；未关联资料作为课程参考，支持关闭复习引用。Tutorial 可记录具体小问错题，Lab 可记录学习与练习进度。
- **统一 AI 用量显示**：简洁显示总量、输入与输出；展开查看缓存、推理、线程累计与上下文窗口。DeepSeek 费用保留估算；token 用量不是账号剩余额度。
- **界面与语言**：统一卡片、对话、加载状态与用量面板；作业 / Tutorial / Lab 分类栏更宽，窄窗口自动换行。日程、时间规则和待办等系统 AI 回复跟随界面语言。

## 安装与升级

要求 **Obsidian 桌面版 1.4.0 或以上**。插件使用 Node.js、Electron 与本地文件系统，不支持移动版。

1. 下载 Release 中的 `learning-hub-1.1.0.zip`，或分别下载 `main.js`、`manifest.json`、`styles.css`。
2. 将三个文件直接放入 `<vault>/.obsidian/plugins/learning-hub/`。自定义了配置目录时使用对应目录。
3. 重启 Obsidian，在「设置 → 第三方插件」启用 Learning Hub。
4. 点击学习空间图标，或运行「Learning Hub: 打开学习主页」。

升级时备份自己的 vault，只替换这三个程序文件，保留已有运行数据。安装不需要 Python、npm 依赖或源码模块。GitHub 自动生成的源码压缩包不等于插件安装包。

也可用 BRAT 添加仓库 `haoyuanzhang2007/obsidian-learning-hub`；发布 tag 为 `1.1.0`，与 manifest 版本一致。GitHub 发布不代表已进入 Obsidian 官方社区插件列表。

## 第一次使用

插件建立 `Home.md`、`Courses/Courses.md`、`学习系统/` 下的日程／待办／复盘入口、`Draft/` 与项目／课外学习入口。默认学期随当前日期创建，不预置课程。

在插件设置中创建学期和课程，例如代码 `COMP 1001`、名称 `Introduction to Computing`。课程代码使用四个英文字母、空格、四位数字，可附加连字符后缀。上传自己的 Syllabus，核对 Codex 解析结果后确认应用。

在课程页上传讲次 PDF。入口、学习阶段与间隔复习位于摘要前面，方便进入预习或回忆。生成内容结合来源、知识点、联系、应用与学习目标；模型无法确认的内容应显示不确定性。学习资料保留在 vault 中，可独立打开。

## AI 与 PDF 配置

| 服务 | 职责与配置 |
| --- | --- |
| Codex | Syllabus、讲次内容、题目、作业与练习解析、估算和排程。安装并登录自己的 Codex CLI，确认 `codex app-server` 可用；设置可执行文件、模型、思考强度与并发数 |
| DeepSeek | 学习助手、待办修改、日程调整、时间规则对话、选文解释及可选草稿标题／仓库指南校订。填写自己的 HTTPS Chat Completions 地址和 API key |
| PDF 工具 | 安装 Poppler 的 `pdftotext`；插件检查常见位置及进程 PATH，也可填写绝对路径。扫描 PDF 请先 OCR |

Codex 默认可执行文件为 `codex`。桌面启动后无法找到时，在终端查出实际路径并填入设置；模型与权限以自己的账号实际可用情况为准。插件以只读、无需工具审批的 Codex 请求生成结构化结果，由插件按对应流程核对与保存。

DeepSeek 默认地址为 `https://api.deepseek.com/chat/completions`，API key 初始为空。自定义服务需兼容插件的请求格式。费用仅为估算，价格可在设置中更新；自定义接口不套用官方价格。

参考：[Codex CLI 文档](https://developers.openai.com/codex/cli)、[DeepSeek 价格说明](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

**语言设置**：中文与 English 界面可切换。系统 AI 回复跟随界面语言；学习资料和学习助手分别使用自己的语言设置。已生成笔记不会随切换而翻译。

## 作业、Tutorial 与 Lab

从「作业与练习」选择类别，上传自己的资料。Tutorial / Lab 可在一次上传中组合多个文件，选择每份文件的角色，关联讲次，并设置是否作为复习参考、是否建立待办。不会自动导入任何示例课程文件。

AI 解析会区分完整题目、具体小问、已提供答案、代码模板与来源页码／Cell。Notebook 只读取文本和已保存的纯文本输出，不执行代码；代码练习使用本机关联编辑器打开。参考答案在详情中折叠展示，不把模板当已完成答案。

复习生成和学习助手会参考当前讲次关联的资料与允许引用的课程资料，不将无关联的材料伪装成讲次来源。资料无法读取、来源冲突或内容不确定时保留提示。修改文件角色后需重新解析，以免引用旧分类结果。

AI 估时写入关联待办；手动填写的预计用时优先，完成状态、紧急和置顶状态保持。作业与 Tutorial 支持大题或具体小问错题；重复选择不重复建记录。

## 时间规则与日程

默认每天 08:00–22:00 可学习，仅为初始值；时区来自本机。先设置实际起床、睡眠与可学习时段，也可配置自己的严格周规划、饭点、固定活动及单日例外。

- LEC 必须参加；TUT / LAB 在需要参加时勾选，可保存重复参加规则。
- 午餐、晚餐各一小时；运动尽可能保留一小时，包含洗澡。严格规划启用时遵循规划的具体时间边界。
- 可通过 DeepSeek 对话设置某日某时段可用／不可用、全天或部分休息。预览后确认应用，不会自动重排已确认日程。
- 「AI 安排七天」由 Codex 按可用时段、忙碌安排和任务优先级生成未确认日期的草案；紧急优先，置顶不改变排程优先级。
- 「AI 调整日程」由 DeepSeek 连续对话移除、替换或移动安排；检查冲突后选择日期确认。
- 任务总览展示七天的项目与学习事项；三日日历展示完整生活安排，并标出休息日／休息时段。日历可切换日期，当前选中日期更宽。
- 不再自动滚动重排；放不下的任务保留为未安排，不强行占用休息、睡眠或已确认安排。

## 可选：Google Calendar

只读同步，不新增、修改或删除 Google 日历事件。

在自己的 Google Cloud 项目启用 Calendar API，创建 Desktop app OAuth 客户端，按要求填写 Client ID／Client Secret，在插件中授权并选择日历。测试状态下需添加自己的测试账号，授权过期时重新连接。

参考：[Google 桌面应用快速入门](https://developers.google.com/workspace/calendar/api/quickstart/nodejs)。连接由使用者独立完成，不继承其他应用的日历授权。

## 数据与隐私

发布仓库和安装包不包含个人笔记、资料、任务、作息模板、聊天历史、API key、OAuth 客户端或授权 token。运行设置、学习状态与聊天记录位于当前 vault 的隐藏 `.learning-hub/` 目录；这些是自己的本地数据，升级时保留。

隐藏目录并非加密保险库，也不会自动阻止同步。API key 和日历授权属于安装者设置；同步 vault 时请管理同步范围。

AI 请求会发送所选资料、当前页面、引用内容或相应任务上下文到配置的服务。Notebook 不执行，Google 日历只读。仓库指南的 AI 自动校订默认关闭。插件没有遥测或维护者数据接收端点。

## 从源码构建

源码入口为 `plugin.js`，功能模块在 `modules/`。根目录 `main.js` 为打包入口，请勿直接编辑。

```bash
python3 build.py
python3 scripts/package-release.py
```

构建只使用 Python 标准库；生成根目录与 `dist/` 的 `main.js`。安装 ZIP 只含 `main.js`、`manifest.json`、`styles.css`。GitHub Actions 验证构建，Release 由维护者账号发布。

## 使用限制

仅支持桌面；PPT/PPTX 可归档但不解析，扫描 PDF 需 OCR。网络、服务权限、上下文窗口和超时可能影响 AI 生成。内容需核对，Syllabus、预习、主笔记、复习问题与 AI 日程保留草案确认流程；作业与练习整理可自动生成解析结果和待办。上传成功不等于 AI 解析成功。

报告问题时附版本、操作步骤与脱敏错误信息，不提交运行数据或密钥。
