# Changelog

## 1.1.0 — 2026-10-07

- Seven-day task overview and focused three-day calendar with complete routines and rest.
- Codex planning for unconfirmed days, separate DeepSeek schedule/time-rule conversations, conflict validation and explicit application.
- Urgency independent of pinning, optional duration estimates and ongoing projects.
- Lesson-based preview, recall and unlocked review tasks; no calendar-only phantom lessons in the task list.
- Rich lesson guides, learning entries before summaries, recall loading feedback and consistent question layouts.
- Homework duration estimates, linked tasks, detail pages and nested subquestion mistakes.
- Shared Homework / Tutorial / Lab library, wider category tabs, multi-file uploads, per-source roles and Notebook text extraction without execution.
- Tutorial / Lab context in spaced review and the assistant, with lesson/course scope, answers, code templates, sources and stale-analysis handling.
- Shared compact AI token panels with expandable cache, reasoning, thread and context details, plus DeepSeek cost estimates.
- System AI language follows UI language while learning-content and assistant settings remain separate.
- Consistent responsive materials, dialogs, scheduling and AI progress UI.
- Empty personal defaults, date-based blank-vault initialization and portable executable discovery in the public build.

## 1.0.0 — 2026-10-04

First public release of Learning Hub.

- Native Obsidian learning home, semester and course workspaces.
- Syllabus import, lecture materials, preview, confirmed main notes, recall and spaced review.
- Homework and independent Lab Session workflows.
- DeepSeek assistant, selection explanations, annotations and study progress rings.
- Tasks, rolling schedules, fixed commitments, availability and retrospective views.
- Read-only Google Calendar integration and local Codex app-server integration.
- Chinese and English interface, assistant and generated-content settings.
- Blank-vault initialization with generic directories, an empty course list and a date-based default semester.
- Runtime settings and learning state stored in the vault's hidden `.learning-hub/` directory; no runtime data shipped with the plugin.
- Self-contained installation entrypoint and clean release archive.
